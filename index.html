Pest and Disease Monitoring System for Banana Lakatan Farming Using CNN Algorithm

An agricultural AI system designed to help farmers identify banana pests and diseases through image classification. It applies Convolutional Neural Networks (CNNs), computer vision, and image processing for faster and more consistent crop monitoring.

The system is connected to a hardware-based automated spraying approach — creating a fully integrated AI + IoT + Smart Agriculture solution.

Goal Faster, consistent banana crop monitoring

Beneficiaries Lakatan banana farmers

AI · Computer Vision · Deep Learning

PlantDoc — Plant Disease Detection System

A deep-learning system capable of detecting 33 types of plant diseases across a wide variety of plants. Unlike single-crop solutions, PlantDoc is designed to be crop-agnostic — users can upload any leaf image and receive a diagnosis with confidence scores.

Built with CNN-based image classification and exploring transformer-based vision approaches for improved accuracy on complex, real-world leaf images.

Coverage 33 disease types detected
Scope Works across multiple plant species
Models CNN + transformer vision
